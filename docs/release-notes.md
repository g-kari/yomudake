# 更新記録

## URL変換時の下書き保護

- 保存していないタイトル・本文がある場合は、URL変換で置き換える前に確認します。キャンセルした場合は変換リクエストを送らず、編集中の内容を保持します。
- 新規の空の下書きでは、URLだけを入力してそのまま変換できます。
- 変換に失敗した場合やMarkdown・タイトル・出典URLの形式が不正な応答が返った場合は、現在のタイトル・本文・出典を保持します。空白だけの手編集も、置き換える前に確認します。
- 変換中に新しい入力が発生した場合や画面を閉じた場合は、ブラウザー側のリクエストを中止し、古い応答を画面へ反映しません。Cloudflare側の処理停止を保証するものではありません。
- 連続クリックで同じ変換を二重に開始しません。公開確認チェックは、変換結果を反映したときに解除します。

`npm run check` に、実際のReact編集画面をDOMシミュレーションで操作する合成APIの回帰テストを追加しました。Happy DOMはテスト用の依存関係で、Workerと公開記事の配布物には含めません。ブラウザーによる本番Accessログイン・実AI変換・本番デプロイの検証は含みません。
