# 更新記録

## 保存操作時の下書き保護

- 下書き保存と公開は、記事一覧の更新が終わるまで1件ずつ処理します。連続クリックで別の記事IDを作ったり、公開・非公開を同時に送信したりしません。
- 保存中に新しい入力が届いた場合、送信済みの内容と編集中の変更を区別します。新しいタイトル・本文・出典と未保存の警告を保持し、再保存が必要だと表示します。
- 保存失敗や確認できない応答では入力を保持します。再試行は同じ記事IDを使用します。保存に成功して記事一覧だけを取得できなかった場合は、その違いを表示します。
- 古い一覧の応答は保存後の一覧を置き換えません。画面を閉じた後の応答は、再度開いた編集画面へ反映しません。送信済みの保存処理をサーバー側で取り消す保証はありません。

実際のReact編集画面をHappy DOMと合成APIで操作する保存の回帰テストを追加しました。実ブラウザーの描画、本番Access・AI・D1、複数タブや別端末からの同時保存は、この検証の対象ではありません。

## URL変換時の下書き保護

- 保存していないタイトル・本文がある場合は、URL変換で置き換える前に確認します。キャンセルした場合は変換リクエストを送らず、編集中の内容を保持します。
- 新規の空の下書きでは、URLだけを入力してそのまま変換できます。
- 変換に失敗した場合やMarkdown・タイトル・出典URLの形式が不正な応答が返った場合は、現在のタイトル・本文・出典を保持します。空白だけの手編集も、置き換える前に確認します。
- 変換中に新しい入力が発生した場合や画面を閉じた場合は、ブラウザー側のリクエストを中止し、古い応答を画面へ反映しません。Cloudflare側の処理停止を保証するものではありません。
- 連続クリックで同じ変換を二重に開始しません。公開確認チェックは、変換結果を反映したときに解除します。

`npm run check` に、実際のReact編集画面をDOMシミュレーションで操作する合成APIの回帰テストを追加しました。Happy DOMはテスト用の依存関係で、Workerと公開記事の配布物には含めません。ブラウザーによる本番Accessログイン・実AI変換・本番デプロイの検証は含みません。


## HTML書き出しの中継変換抑止

HTMLのダウンロード応答だけに `Cache-Control: no-store, no-transform` を指定し、CDNによる本文への計測スクリプト追加を抑止します。本文、Markdown書き出し、公開閲覧、管理画面、認証、既存CSPは変更しません。合成データでヘッダーと既存経路の回帰を検証し、配備後に実際のHTMLダウンロードの応答バイトを再確認します。保存したHTMLを実行する試験や、Cloudflare全体の計測・セキュリティ設定の変更は含みません。

## 自分だけのノート UI

選択した D 案に合わせ、記事一覧を淡い黄色のインデックス、本文を白いノートページとして整理しました。青みのある文字と控えめな青緑の操作ボタンを使用し、管理画面・公開記事の日本語本文を読みやすいサイズと行間にしています。

- 最初の表示と保存した記事を開くときはプレビューを選択します。Markdown とプレビューは同時表示せず、切り替えても入力・未保存状態を保持します。新しい下書きは Markdown の編集から始めます。
- 記事の選択状態、下書き／公開中、保存した記事の出典と作成日を表示します。安全でない元URLはリンクにしません。
- 公開確認チェック、下書き保存、非公開で保存、公開・更新、共有URL、サインアウトを維持します。モバイルでも公開ページとサインアウトへの移動を表示します。
- 未保存内容の破棄確認、変換・保存の二重送信や古い応答の保護、API・認証・配備設定・マイグレーション・HTML書き出しの no-transform は変更しません。

型チェック、ビルド、実 React 編集画面の合成 API 回帰テストで確認します。本番の本人認証・実 AI 変換・D1 書き込みはこの UI 検証の対象ではありません。
